# シュレーディンガーの鏡 (Schrödinger’s Mirror)

> **「観測されるまで、状態は確定しない。」**  
> 誰かの前やカメラの前で「大丈夫な自分」を演じ続け、泣く場所を失った現代人のための感情排出・揮発デバイス。

---

## 概要

本作品は、Webカメラでユーザーの姿を捉えながらも、分厚い「結露（水蒸気の霧）」によって自らの輪郭をあいまいに覆い隠すインタラクティブ・ミラーです。

通常、鏡やカメラは「自分を克明に記録し、客観視させる（自己監視や自己検閲を強いる）」装置です。本作品はそれを逆転させ、**「はっきりと映さないことで主観と未確定さを守り、指や文字で吐き出された弱音を水蒸気として蒸発・昇華させる」** というコンセプトを持っています。

---

## 主な機能と体験

1. **時間帯連動のファーストビュー（4つの時間軸）**
   - アクセスした実際の時刻に応じて、心象風景に寄り添う詩的なメッセージが動的に変化します。
   - `0:00 〜 4:59`：静寂の時間（完全な無防備さ）
   - `5:00 〜 8:59`：心の鎧をまとう前（社会に出る前のひととき）
   - `9:00 〜 17:59`：視線・喧騒の中（過剰な視線からの束の間の避難）
   - `18:00 〜 23:59`：静寂へ向かう時間（一日の役目を終えた解放）

2. **結露の拭いインタラクション**
   - マウスや指でなぞることで、結露がぬぐわれ、その奥に一瞬だけ素顔や瞳が覗きます。
   - 速度に応じて線の太さが変化し、動かすスピードに応じたガラスの摩擦音（キュッ）がリアルタイムに響きます。

3. **ローマ字 ➔ ひらがな直接縦横タイピング ＆ 揮発（昇華）**
   - キーボードを打つと、漢字変換不要でひらがながガラスを削るように刻まれます。
   - 書かれた言葉は **7秒間留まり、その後3秒（7〜10秒）かけて周囲の湯気に溶け込み、完全に蒸発** して消え去ります。
   - データやログは一切保存されず、なかったことにしてくれる絶対的な救済を提供します。

4. **プロシージャル・音響システム**
   - 浴室に響く静かな水滴音（ポタッ…）と、ガラスの擦れ音が空間の没入感を高めます。

## 技術仕様

- **フロントエンド:** Vanilla HTML5, CSS3, JavaScript (ES6+)
- **グラフィックス:** HTML5 Canvas (`CanvasRenderingContext2D` - `globalCompositeOperation = 'destination-out'`)
- **オーディオ:** Web Audio API (プロシージャル合成 / AudioBuffer)
- **カメラ:** `navigator.mediaDevices.getUserMedia`
- **フォント:** Google Fonts (`Zen Kurenaido`)
- **完全スタンドアロン:** ビルドツール不要、GitHub Pages等で即座に動作
